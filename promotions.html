How this works

A prototype of a promotions page

In a real build each offer would link to a campaign, the code would be validated on the server and the countdown would run against a real expiry date. Here, the code copies to the clipboard and the links take you to the matching drinks.

A code you can copy

Every sample offer carries a code. Selecting “Copy code” puts it on your clipboard and confirms with a toast notification.

Direct links to products

Each card lists the drinks the offer applies to, so a visitor can jump straight to a product page and add it to the cart.

Clear expiry dates

Expiry dates are shown in plain language so the visitor always knows how long an offer runs for.
